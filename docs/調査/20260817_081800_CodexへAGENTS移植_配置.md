# Codex 指示の配置

## 読込順（Codex 公式）

1. Global: `~/.codex/AGENTS.override.md` があればそれだけ。無ければ `~/.codex/AGENTS.md`
2. Project: Git root → cwd。各層で `AGENTS.override.md` があればそれを採用、なければ `AGENTS.md`
3. 近いファイルが後に連結され、後段が優先
4. 結合サイズが `project_doc_max_bytes` を超えると打ち切る

## この workspace での実体

| 層 | ファイル | 役割 |
| --- | --- | --- |
| Global | `~/.codex/AGENTS.md` | 共通 Skill、完了整合性、module 表、catalog と同じ常時ルール |
| Catalog | `/home/nyukimi/RenCrow/AGENTS.md` | Cursor 正本。Codex が catalog root で起動したときも読む |
| CORE | `RenCrow_CORE/AGENTS.md` | CORE 固有。global より後段なので CORE 差分が優先 |
| CMD | `RenCrow_CMD/AGENTS.md` | CMD 固有（存在する場合） |

## 正本を更新したあとの再同期

```bash
python3 - <<'PY'
from pathlib import Path
ws = Path("/home/nyukimi/RenCrow/AGENTS.md").read_text(encoding="utf-8")
p = Path("/home/nyukimi/.codex/AGENTS.md")
text = p.read_text(encoding="utf-8")
marker = "# RenCrow Project Rules"
head, _, _ = text.partition(marker)
p.write_text(head + ws, encoding="utf-8")
PY
```

head は `## RenCrow Workspace Rules` 節の導入文まで残し、`# RenCrow Project Rules` 以降を正本で置換する。
