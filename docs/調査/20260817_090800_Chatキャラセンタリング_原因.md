# Chatキャラクター非センタリング — 原因

## 因果

1. Chat は `width >= height` なら **landscape 固定キャンバス**（`portal.js` の `resolveViewportProfile`）。今回 551×540 なので `html.portal-chat-landscape`。
2. 同じ viewport は幅 551px のため `@media (orientation: portrait), (max-width: 700px)` も真。
3. その media 内の規則:

```css
body.room-mode.room-stage.room-chat-mode #chatPortrait{
  left: calc(50% + var(--room-p-avatar-offset-x)) !important;
}
```

（`portal.css` 約 2986–3004 行）

4. `--room-p-avatar-offset-x` の定義場所:
   - `@media (orientation: portrait)` の `body.room-mode.room-stage`（約 2750–2761 行、コメント: PuruPuru 16:9 の左寄り補正）
   - `html.portal-chat-portrait` の Chat body（約 3576 行、`98.25px`）
   - **landscape 固定キャンバスの body には無い**
5. 今回は portrait media が偽なので変数は空。`var()` に fallback も無い。
6. CSS カスタムプロパティの **IACVT**（invalid at computed-value time）:
   - `!important` の `left` はカスケードに勝つ
   - 計算値が無効になると `left` は **unset / 初期値 `auto`**
   - 非 `!important` の `left: 50%`（約 2946 行と landscape 約 3399 行）は **復活しない**
7. `left: auto` + 明示幅 760px の `position:fixed` → 使用値 **left = 0**
8. `.purupuru-avatar` / `#chatPortrait` の `transform: translateX(-50%)` は残る → 幅の半分（380px）左へずれる
9. `body` の `transform: scale(...)`（origin `top left`）でそれが画面座標に写る → キャラクター中心が viewport 左端

## 当たっている `left` 規則（実測 CSSOM）

| media | selector | left | important | 結果 |
| --- | --- | --- | --- | --- |
| （なし） | `body... #chatPortrait` | `50%` | なし | カスケード負け |
| `(orientation: portrait), (max-width: 700px)` | 同上 | `calc(50% + var(--room-p-avatar-offset-x))` | **important** | 変数なし → IACVT → `auto`/`0` |
| （なし） | `html.portal-chat-landscape > body... #chatPortrait` | `50%` | なし | カスケード負け |

## 仕様との衝突

表示倍率仕様は「要素を `vw`/`vh` で viewport 追従させない」「外側 fit はキャンバス root の単一 scale のみ」とする。

`max-width: 700px` 側は viewport 連動の旧モバイル規則で、固定キャンバス landscape と同時に発火する。狭い Cursor ペイン（ほぼ正方形）は仕様上 landscape になるため、**「landscape キャンバス + 700px モバイル left」** が重なる。

portrait 用オフセットは「PuruPuru がモバイル stage で左寄り」への意図的補正。変数が無い landscape では補正ではなく **left 全体の消失** になる。

## 否定した仮説

| 仮説 | 判定 |
| --- | --- |
| `fitChatCanvas` の offsetX 誤り | 否定。offsetX=0 は幅フィットとして正しい |
| landscape `#chatPortrait` に `left:50%` が書いていない | 否定。書いてあるが `!important` に負ける |
| 内側 560px vs slot 760px の左寄せが主因 | 副次の可能性はあるが、今回 slot 自体が左端。rect は 760px |
| portrait 専用 `left: calc(50% + 98.25px)` が今回適用 | 否定。`portal-chat-portrait` ではない |

## テストの穴

`RenCrow_PORTAL/internal/portal/server_test.go` は CSS 文字列に `left:calc(50% + var(--room-p-avatar-offset-x)) !important` が **含まれること** を見ている。  
「landscape 固定キャンバスかつ max-width:700px で変数未定義 → `left` が 0 になる」は見ていない。
