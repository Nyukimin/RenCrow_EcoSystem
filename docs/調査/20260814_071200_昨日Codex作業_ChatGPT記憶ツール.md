## 何をするか

ChatGPT export directory / ZIP を read-only で開き、CORE 所有の L3 import 契約へ渡す private JSONL にする。

- 入力: ChatGPT export
- 出力: `rencrow.chatgpt_l3.v1` JSONL + manifest
- しないこと: CORE DB への直接接続、LLM 推論、話題や UserMemory の自己確定

変換後の CORE 経路:

```text
CLI convert
  -> POST /viewer/memory/import/chatgpt  (既定 dry-run、apply=true で L3 commit)
  -> ProfilePromotion worker（current branch の user 発言のみ）
  -> GET /viewer/memory/profile-promotions
  -> POST /viewer/memory/import/chatgpt/confirm  (既定 dry-run、apply=true で confirmed)
```

