所有ファイル:

- `RenCrow_CORE/internal/infrastructure/persistence/conversation/l1sqlite/l1_sqlite_chatgpt_raw_import.go`
- `RenCrow_CORE/internal/infrastructure/persistence/conversation/l1sqlite/l1_sqlite_chatgpt_raw_import_test.go`

## 変更前

`validateChatGPTLegacyEvent` は `json.Marshal(event.Meta)` と期待 `metaJSON` の文字列一致を要求した。`content_sha256` が一致しても optional／round-trip 差で `unavailable` になり、legacy 行への Common Raw apply が止まる。

## 変更後

必須 identity は存在し、正規化 JSON として一致しなければならない。

- `external_source`（`chatgpt_export`）
- `export_id`
- `conversation_id`
- `message_id`
- `node_id`
- `content_sha256`

`content_sha256` 不一致は `source_changed`。

optional は欠落を許可し、存在するときだけ期待値と一致させる。

- `conversation_title`, `parent_node_id`, `child_node_ids`, `on_current_branch`
- `original_role`, `content_type`, `artifact_content`, `artifact_metadata`

追加キーは `active` のような lifecycle 余剰を許可する。`owner_id` / `user_id` / `scope` / `evidence_event_ids` は拒否する。

比較は map を一度 JSON round-trip してから行う。`json.RawMessage` と object の文字列差では落とさない。
