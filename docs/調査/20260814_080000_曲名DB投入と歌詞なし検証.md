# LyricFind曲名をhobby_graphへ投入

- 日付: 2026-08-14 08:00 JST
- 入力: `docs/調査/20260814_073800_LyricFind曲名一覧/`
- CORE: `POST /viewer/hobby-graph/music/import` apply=true
- DB: `/srv/rencrow/db/core/databases/hobby_graph/hobby_graph.sqlite`

## 投入結果

| 項目 | 件数 |
| --- | ---: |
| ソース曲名 | 1056 |
| song items | 1056 |
| lyrics rows | 1056 |
| lyrics_text あり | 0 |
| storage_mode=full_text | 0 |
| storage_mode=reference_only | 1056 |
| performed 関係 | 1056 |
| artist items | 18 |

artistが18なのは、LyricFindの歌唱creditがコラボ表記（例: `SUPER BEAVER and 長屋晴子`）の曲を別artist itemとして保存したため。カタログ自体は指定4組。

## 歌詞なしチェック

- 投入前JSON: `lyrics` / `lyric` / `lyrics_text` / `snippet` があれば `import-titles` が拒否
- CORE import: `reference_only` で `lyrics_text` があると 400
- DB制約: `CHECK(storage_mode = 'full_text' OR lyrics_text IS NULL)`
- 実DB: `lyrics_text` は全件 NULL。syntax の token/line/vocab は全件 0、`non_reconstructable=1`

rencrow-lyrics-catalog import-titles \
