## 範囲（今回）

`conversation_l1` の既存 `l1_knowledge_item` を削除・書き換えせず、`raw_text` の SHA-256 が `raw_hash` と一致することを確認して Common Raw に取り込む。既存 ID を output とする pending／completed projection receipt を書く。

- `allow_empty=false`
- 0件は `invalid` で閉じ、coverage `ready=false`
- hash 不一致は `source_changed`、Raw を書かない
- 冪等 replay は同一 manifest／record へ収束
- JSONL 停止、`knowledge_memory.storage` 切替、CMD／owner API、live E2E は含めない
