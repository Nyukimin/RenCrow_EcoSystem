# 記憶システムの数え方

確認日時: 2026-08-17 08:47 JST  
正本: CORE `docs/02_機能仕様.md`（Memory / Data Capability Catalog）、`docs/04_アーキテクチャ概要.md`（RecallPack）  
live: `GET /viewer/databases/catalog` と Viewer「DB Catalog」= **20件を読込済み / Available 20**

## 答え（混ぜない）

| 数え方 | 個数 | 意味 |
| --- | ---: | --- |
| 製品の記憶システム | **1** | CORE が所有する Memory／Recall。入口は RecallPack。独立した記憶製品は増やさない |
| catalog の永続 store | **20** | すべて広義の Memory。`storage.databases` の固定 key |
| 会話想起の層 | **4** | RecallPack の L0 / L1 / L2 / L3 |
| 会話の投影ドメイン | **3** | Conversation L3、UserMemory、reviewed Knowledge |
| Common Raw | **0（catalog 外）** | 21番目の DB ではない。`conversation_l1` 台帳 + `raw_source_dir` object の論理層 |

## 20 store（live catalog と 02 の固定一覧は一致）

`conversation_l1`、`conversation_archive`、`tool_registry`、`glossary`、`movie_catalog`、`hobby_graph`、`investment`、`advisor`、`sandbox`、`dci`、`skill_governance`、`workstream`、`revenue`、`persona_architecture`、`browser_trace_to_api`、`complexity_hotspot`、`super_agent_harness`、`ai_workflow`、`knowledge_memory`、`durable_store_workflow`

会話の本体に近いのはこのうち `conversation_l1` と `conversation_archive` と `knowledge_memory`。残りは映画・用語・投資・運用監査など、同じ広義 Memory 契約の別 store。

## 層（1システムの内部）

```text
Common Raw（原本、Recall禁止）
  -> Conversation L3 / UserMemory confirmed|pinned / reviewed Knowledge
  -> RecallPack（L0 短期、L1 raw検索、L2 要約、L3 長期事実）
```

Qdrant は L3 の vector follower。catalog の 21個目ではない。legacy DuckDB は旧互換。Redis は active-thread 投影であり SQLite 正本の参加者ではない。
