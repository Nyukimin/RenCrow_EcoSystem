## やってはいけないこと

- pending を空にするために candidate を自動 confirmed にしない。
- backup 失敗を NTFS dirty force や root filesystem への退避で通さない。
- vector を通すために CORE から Ollama / 別名 backend へ直結しない。
- canonical import が blocked のまま、短縮ルートや test double で「取込成功」としない。
- 今回の調査で `retry` / `apply` / restart / mount は実行していない。
