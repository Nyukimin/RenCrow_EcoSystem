## 推奨（仕様整合）

固定キャンバス Chat では、viewport 連動の `@media (max-width:700px)` が **`#chatPortrait` の `left` を上書きしない**ようにする。

例:

- landscape / portrait の固定キャンバス規則を `!important` で完結させる、または
- `html.portal-chat-fixed-canvas` 配下では 2986 行付近の `#chatPortrait` left 上書きを除外する

これで `left:50%`（landscape）または portrait 正本の `left:calc(50% + 98.25px)` が残る。

## 回避（対症）

`var(--room-p-avatar-offset-x, 0px)` のように fallback を付ける。

- IACVT は消える（今回の診断では `0px` で `left:960px` になった）
- ただし `max-width:700px` が landscape キャンバス上でも発火し続ける。仕様の「viewport へ要素を追従させない」とはまだ食い違う（width/height の `vw`/`dvh` 上書きも同 media にある）

## 検証してほしい条件

1. 今回と同じ **幅 ≤700 かつ width ≥ height**（Cursor 狭いペイン）
2. 通常の横長（例 1280×720）— もともと 700px media が偽なので現状でも中央のはず
3. 縦長 portrait キャンバス — 変数定義あり。既存の左寄り補正を壊さないこと
