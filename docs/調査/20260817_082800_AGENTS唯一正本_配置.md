# AGENTS.md 唯一正本の配置

## 読み方

- Cursor catalog workspace: 正本 `AGENTS.md` を直接読む。User Rule は「正本を読め」とだけ言う。
- Cursor 子 workspace: User Rule が絶対パスで正本を指す。本文は User Rule に置かない。
- Codex 任意 repo: 全局入口が正本への symlink なので、Git root より上を辿らなくても正本が載る。
- モジュール `AGENTS.md` は後段に連結される。弱体化は禁止、所有範囲の追加だけ。

## 更新手順

正本を編集する。コピー再生成は不要。

symlink が通常ファイルに戻っていたら:

```bash
rm -f /home/nyukimi/.codex/AGENTS.md
ln -s /home/nyukimi/RenCrow/AGENTS.md /home/nyukimi/.codex/AGENTS.md
```

Cursor `.mdc` に本文が戻っていたら、ポインタだけに戻す。
