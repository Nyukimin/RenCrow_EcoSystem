# Cursor 指示の配置

## 公式の四種

| 種類 | 置き場所 | 範囲 |
| --- | --- | --- |
| Project Rules | `<repo>/.cursor/rules/*.mdc` | その codebase |
| User Rules | Customize → Rules、実体は `~/.cursor/rules/*.mdc` | 全プロジェクト |
| Team Rules | Cursor dashboard | チーム |
| AGENTS.md | プロジェクト root とサブディレクトリ | その workspace |

衝突時の優先: Team → Project → User。適用されるものはマージされる。

## この workspace での実体

| 層 | ファイル | 役割 |
| --- | --- | --- |
| User | `~/.cursor/rules/rencrow-workspace.mdc` | catalog と同じ常時ルール。CORE 単体 workspace でも効く |
| Catalog AGENTS.md | `/home/nyukimi/RenCrow/AGENTS.md` | Cursor catalog workspace の正本 |
| CORE Project Rules | `RenCrow_CORE/.cursor/rules/*.mdc` | CORE 固有（今回は未変更） |
| CORE AGENTS.md | `RenCrow_CORE/AGENTS.md` | CORE 固有実務 |

## 正本を更新したあとの再同期

```bash
python3 - <<'PY'
from pathlib import Path
ws = Path("/home/nyukimi/RenCrow/AGENTS.md").read_text(encoding="utf-8")
mdc = Path("/home/nyukimi/.cursor/rules/rencrow-workspace.mdc")
text = mdc.read_text(encoding="utf-8")
marker = "# RenCrow Project Rules"
head, _, _ = text.partition(marker)
mdc.write_text(head + ws, encoding="utf-8")
codex = Path("/home/nyukimi/.codex/AGENTS.md")
ct = codex.read_text(encoding="utf-8")
head, _, _ = ct.partition(marker)
codex.write_text(head + ws, encoding="utf-8")
PY
```
