# Chat画面のキャラクターが中央にいない — 概要

- 日時: 2026-08-17 09:08 JST
- 対象: `RenCrow_PORTAL` の Chat（`http://127.0.0.1:18791/chat`）
- 結論: **PuruPuru の描画偏りではなく、`#chatPortrait` の `left` が無効化され、左端基準＋`translateX(-50%)` になっている。**
- 修正は未実施（調査のみ）。

## 何が起きているか

仕様（`RenCrow_PORTAL/docs/PORTAL表示倍率仕様.md`）では、Chat は選択中 1 体を **landscape 1920×1080 または portrait 393×852 の中央 slot** に置く。キャンバス全体を等比 scale して viewport 中央へ寄せる。

実画面では Shiro の右肩だけが画面左端に見え、slot の中心は viewport 左端付近にある。

## 原因の一行

狭い viewport（幅 ≤700px）で `@media (orientation:portrait), (max-width:700px)` の **`left: calc(50% + var(--room-p-avatar-offset-x)) !important` が勝ち、変数未定義のため IACVT で `left` が `auto`（使用値 0）になる。** landscape 用 `left:50%` は `!important` ではないので負け、無効化された `!important` のあとに初期値へ落ちる。

- `RenCrow_PORTAL/internal/portal/web/portal.js`（`fitChatCanvas`、profile は `width >= height` なら landscape）
