## 何をするか

保存済み HTML を歌手・楽曲・歌詞参照・非復元 Syntax 特徴量の `rencrow.music_catalog.v1` JSONL へ変換する。

既定ではネットワーク取得も本番 DB 書込もしない。LyricFind は許可取得まで `saved_html_only` かつ `full_text_storage=false`。

権利境界:

- 既定 `rights-status=unknown` → 本文を保存せず hash と特徴量のみ
- 全文保存には `licensed | public_domain | user_owned`、`--license-reference`、`--include-licensed-text` が全部必要

CORE 経路:

```text
CLI parse saved HTML
  -> POST /viewer/hobby-graph/music/import  (既定 dry-run、apply=true で hobby_graph.sqlite)
```

Agent 向け semantic Tool（CORE 所有）:

- `music_catalog.lookup` — 歌手/楽曲 metadata、完全一致、最大20件
- `lyrics_catalog.lookup` — `information=rights | syntax | full_text`
