# AGENTS.md を唯一の正本にする

日時: 2026-08-17 08:28 JST  
正本: `/home/nyukimi/RenCrow/AGENTS.md`

## 方針

workspace 常時ルールの本文は catalog `AGENTS.md` だけに置く。Codex / Cursor 側へ全文コピーしない。

| 入口 | 形 | 本文 |
| --- | --- | --- |
| catalog `AGENTS.md` | 正本 | あり |
| `~/.codex/AGENTS.md` | 正本への symlink | なし（同一ファイル） |
| `~/.cursor/rules/rencrow-workspace.mdc` | alwaysApply の参照 | ポインタのみ |
| `CLAUDE.md` | 入口 | 正本へ委譲 |
| `RenCrow_CORE/AGENTS.md` 等 | module-local | catalog の複製ではない |

## 実施

1. 正本に「複製禁止」「完了整合性」「Workspace Module Roots」「Skill は上書きしない」を集約した。
2. `~/.codex/AGENTS.md` を通常ファイルから symlink へ差し替えた。
3. Cursor `.mdc` から本文を削除し、正本パスへの参照だけにした。

## 検証

- `readlink ~/.codex/AGENTS.md` = `/home/nyukimi/RenCrow/AGENTS.md`
- 正本と Codex 入口の文字が同一
- Cursor `.mdc` に `## CLI-First` 節が無い（580 bytes）
