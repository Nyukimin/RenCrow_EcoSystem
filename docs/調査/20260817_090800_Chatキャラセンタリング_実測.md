# Chatキャラクター非センタリング — 実測

- URL: `http://127.0.0.1:18791/chat`
- 相手: Shiro
- 計測: Cursor 内蔵 browser（tab `e10aab`）、2026-08-17 09:07 JST 前後

## Viewport と canvas profile

| 項目 | 値 |
| --- | --- |
| layout viewport | 551 × 540（幅 ≥ 高さ → **landscape**） |
| `html` class | `portal-chat-fixed-canvas portal-chat-landscape` |
| `body` class | `room-chat-mode room-partner-shiro` |
| 論理キャンバス | 1920 × 1080 |
| scale | `min(551/1920, 540/1080)` ≈ **0.286979** |
| offsetX / offsetY | 0 / ≈115.03（上下 letterbox） |
| `matchMedia('(max-width: 700px)')` | **true** |
| `matchMedia('(orientation: portrait)')` | **false** |

`fitChatCanvas` の scale / offset は仕様どおり。キャンバス自体は横いっぱいにフィットしている。TOPIC・入力欄・相手切替は画面幅に乗っている。

## `#chatPortrait` の使用値

| 項目 | 値 |
| --- | --- |
| inline style | なし |
| `position` | `fixed`（containing block は transform 付き `body`） |
| `left` | **0px** |
| `right` | 1160px（1920 − 760。左寄せの余り） |
| `width` × `height` | 760 × 626.4（landscape slot 寸法） |
| `transform` | `matrix(1,0,0,1,-380,0)` = `translateX(-380px)`（幅の半分） |
| `getBoundingClientRect()` | x ≈ **-109**, width ≈ **218**, 中心 x ≈ **0** |
| viewport 中心 x | 551 / 2 ≈ **276** |
| ずれ | 中心が約 **275px 左**（左端に中心が乗る） |

幾何の一致:

- 未スケール: `left=0` + `translateX(-380)` → ボックス左端 -380、中心 0（キャンバス左端）
- scale 0.287: 画面上の左端 ≈ -109、幅 ≈ 218。実測と一致

## 診断実験（一時 CSS 変数のみ、永続変更なし）

`document.body` に `--room-p-avatar-offset-x: 0px` を載せた瞬間:

- `left`: **0px → 960px**（1920 の 50%）
- 変数を外すと **0px に戻る**

960px + `translateX(-50%)` なら slot 中心はキャンバス中央（画面上 ≈276px）になる。
