# LyricFind アーティスト全曲収集 — 概要

- 日付: 2026-08-14 07:30 JST
- 指示: [LyricFind](https://lyrics.lyricfind.com/) から曲名・アーティスト名で取得する。アーティストが主、曲名が副。指示したアーティストの全曲を取得する
- 進捗: collector実装完了。対象アーティスト名の指定待ち

## 方針

- アーティスト名の完全一致（表示名またはローマ字名）でslugを確定する
- 一致0件は not found、2件以上は ambiguous で fail-closed。fuzzyは使わない
- slug確定後、charts APIでそのアーティストの全曲URLを取る
- `songs` が空なら全曲。値があれば曲名完全一致だけ残す
- 歌詞本文は保存しない。hash と非復元 Syntax だけを CORE へ渡す
- `/api/v1/lyric` は呼ばない

## 収集経路

```text
config.artists[]
  -> GET /api/v1/search (searchtype=artist)
  -> GET /api/v1/charts (artistid=slug:{slug}, paginate)
  -> GET /lyrics/{slug} HTML (metadata + hash)
  -> POST CORE /viewer/hobby-graph/music/import
```

5分間隔の `rencrow-lyrics-collector.timer` が未取得分を最大20件ずつ `--apply` する。
