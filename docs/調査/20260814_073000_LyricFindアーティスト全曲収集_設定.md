# LyricFind collector 設定

host private config（git外）:

`/home/nyukimi/.rencrow/config/lyrics-collector.json`

```json
{
  "provider": "lyricfind",
  "base_url": "https://lyrics.lyricfind.com",
  "territory": "JP",
  "artists": [],
  "songs": [],
  "batch_limit": 20,
  "target_urls": [],
  "core_import_endpoint": "http://127.0.0.1:18790/viewer/hobby-graph/music/import",
  "request_delay_millis": 1000
}
```

- `artists`: 必須の主キー。LyricFind上の表示名またはローマ字名を完全一致で書く
- `songs`: 空ならそのアーティストの全曲。値があれば曲名完全一致だけ
- `target_urls`: 個別曲URLの追加指定。通常は空
- 取得済みURLは `lyrics-collector-state.json`（configと同じディレクトリ）へ保存する

例（未適用。ユーザー指定後に書く）:

```json
"artists": ["サカナクション"]
```

または

```json
"artists": ["Sakanaction"]
```

binary: `/home/nyukimi/.local/bin/rencrow-lyrics-catalog`
timer: `rencrow-lyrics-collector.timer`（既存の5分間隔）
